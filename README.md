# Cursor Creature Adoption Agency

An interactive Next.js adoption office for imaginary browser companions. Take the compatibility interview, invite a creature to follow your cursor, earn its trust, and file a local adoption certificate.

## Run locally

```bash
npm install
npm run dev
```

The production build is a static Next.js export deployed to GitHub Pages. Adoption records stay in the visitor's browser through local storage; there are no accounts, trackers, or external services.
